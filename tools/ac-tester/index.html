判定の仕組みと前提

読み落とし率: 持続時間 d ms の入力が16.7msごとの読み取りに一度も重ならない確率で、max(0, 1 − d / 16.7) です（例: 6ms → 64%）。

コマンド成功率: 攻撃ボタンを押した時刻を含むフレームから、受付フレーム数だけさかのぼった読み取り結果に、コマンドが順番どおり含まれるかを判定します。読み取りの位相を32通りずらした平均です。攻撃ボタンを押さなかった場合は、最後の方向を押してから20ms後に押したとみなします。

スト6の判定ルール（このツールの前提）: 昇竜は「前を含む方向 → 下を含む方向 → 前を含む方向」が順に並べば成立（623 / 323 / 636 / 626 / 639）。333のように同じ方向が続くだけでは不成立。波動は 2 → 3 → 6 が順に必要（26は不成立）。竜巻は 2 → 1 → 4。真空波動は波動2回。波動の判定で昇竜も成立している場合は、昇竜に化けたとして失敗に数えます。受付フレーム数は波動系11Fが公開されている調査値で、他は仮の値です。

左右: 1P側（右向き）と2P側（左向き）は、入力がどちら向きのコマンドとして成立したかで自動で振り分けます。
