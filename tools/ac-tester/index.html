判定の仕組みと前提

ゲームの動き: ゲームは60fpsで進み、入力は1フレームに3回、不規則なタイミングで読み取ります（WydDの調査）。3回のうちどれがそのフレームの入力になるかは分かっていないため、このツールでは「ランダムに1つだけ使われる」という厳しい想定で再現しています。攻撃ボタンを押したフレームで、直前の入力履歴から技を判定します。優先順位は真空波動拳 → 昇竜拳 → 波動拳 / 竜巻旋風脚 → 通常技です。技の最中に押したボタンは無視します（試行に数えません）。

スト6の判定ルール（このツールの再現）: 昇竜は「前を含む方向 → 下を含む方向 → 前を含む方向」が順に並べば成立（623 / 323 / 636 / 626 / 639）。333のように同じ方向が続くだけでは不成立。波動は 2 → 3 → 6 が順に必要（26は不成立）。竜巻は 2 → 1 → 4。真空波動は波動2回。前歩きからの波動は昇竜に化けます。本物のスト6と完全に同じである保証はありません。

読み落とし率: 持続時間 d ms の入力が、どのフレームでも使われない確率です。上の想定では各フレームで使われる時刻がランダムなので、1フレーム（16.7ms）より長い入力でも外れることがあり、確実に拾われるのは約2フレーム（34ms）以上です。受付フレームは、波動・竜巻11F、昇竜7F、真空波動は各区間10F（最初だけ12F）としています（WydDの調査値。竜巻は波動と同じと仮定）。
