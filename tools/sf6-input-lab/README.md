# SF6 入力読み取り実測ツール（MOD不要）

スト6（PC版）のトレーニングモードに、ミリ秒単位で正確な入力を投げます。ゲームがそれをどう読んだかを画面から自動で記録するツールです。ゲームのファイルには一切触れません。

- **入力を投げる**: Pythonから仮想Xbox 360コントローラー（ViGEmBus / vgamepad）を操作します。待ち時間は細かく制御するので、精度は約0.1msです。
- **読んだ結果を記録する**: トレモの「入力履歴」と画面の動きをキャプチャし、画像照合で判定します。
- **分かること**
  - **実験A**: 短い斜めは読まれるか。「1フレームに3回読む」の正体を判定します。
  - **実験B**: 1フレームの中に3方向を入れるとどうなるか。
  - **実験C**: 受付フレーム（波動・竜巻・昇竜・真空波動）。

## 1. 準備（初回のみ）

### Python を入れる

1. https://www.python.org/downloads/ から最新版（3.12 以降）をダウンロードし、インストールします。
2. インストーラーの最初の画面で **「Add python.exe to PATH」にチェック** を入れます。
3. このフォルダ（`sf6-input-lab`）でターミナル（PowerShell）を開き、次を実行します。

```
python -m pip install -r requirements.txt
```

途中で **ViGEmBus（仮想コントローラーのドライバ）** のインストール画面が出たら、そのまま進めてください。終わったらPCを再起動します。

### スト6 の設定

- **表示モード**: 「ボーダーレスウィンドウ」か「ウィンドウ」にします。排他フルスクリーンだと、画面キャプチャが真っ黒になることがあります。
- **トレーニングモード**: リュウ（クラシック操作）、1P側、初期位置。
- **トレモ設定**:
  - 入力履歴の表示: ON
  - SAゲージ: 無限（実験Cの真空波動用）
  - ダミーの状態: 立ち（何もしない）
- **コントローラー**: レバーレスなど、他のコントローラーは **抜いておきます**。仮想コントローラーが1P以外として扱われるのを防ぐためです。
- **キー設定**: 弱P は X ボタン（初期設定）。トレモの「位置リセット」に割り当てたボタンを `data/config.json` の `reset_button` に合わせてください（初期値は BACK）。

## 2. 使い方

それぞれのコマンドは、実行すると5秒のカウントダウンがあります。その間に **スト6のウィンドウをクリックして前面に** してください。

| 手順 | コマンド | 内容 | 所要時間 |
| --- | --- | --- | --- |
| 1 | `python lab.py ping` | 仮想コントローラーの入力がトレモに届くか確認 | 10秒 |
| 2 | `python lab.py setup` | 画面の読み取り位置をマウスで指定 | 1分 |
| 3 | `python lab.py learn-icons` | 入力履歴の方向アイコンを自動で覚える | 15秒 |
| 4 | `python lab.py run A` | 実験A（22通り×30回） | 約13分 |
| 5 | `python lab.py run B` | 実験B（2通り×30回） | 約1分 |
| 6 | `python lab.py learn-moves` | 各技の画面の動きを覚える（実験C用） | 2分 |
| 7 | `python lab.py run C` | 実験C（受付フレーム） | 約15分 |
| 8 | `python lab.py report` | 結果を `data/report.md` にまとめる | すぐ |

回数は `--n` で変えられます（例: `python lab.py run A --n 50`）。何度実行しても結果は `data/` にたまり、report はすべてを合算します。

### setup で選ぶ3つの範囲

1. **いちばん新しい行の方向アイコン**: 入力履歴の最新の行の、矢印アイコンだけを囲みます。
2. **2番目の行の方向アイコン**: 同じように、1つ前の行の矢印を囲みます（行の間隔の計算に使います）。
3. **自キャラとその前方**: 技が出る範囲（波動拳が飛んでいく途中まで、昇竜拳で上がる高さまで）を囲みます。

## 3. 結果の読み方

`data/report.md` に次が出ます。

- **実験A**: 斜めの長さ（1〜30ms）ごとに、入力履歴に斜めが残った割合を出します。3つのモデルの予測と並べ、一番近いモデルを判定します。
  - **1フレーム1回（スト5方式）**
  - **3回読み・1つだけランダムに使う**（厳しい想定）
  - **3回読み・拾った入力は順に全部使う**（甘い想定）
- **実験B**: 1フレームに 2・3・6 を入れたとき、入力履歴にどう残ったかの割合です。
- **実験C**: 方向の間隔（またはボタンまでの間隔）を1フレームずつ延ばし、技が出なくなる境目を出します。精度は ±1フレーム程度です。

`data/export.json` は、AC入力テスターの判定モデルを実測値に合わせるために使います。

## 4. 入力が届かないとき

- **他のコントローラーを抜く**: レバーレスなどが刺さっていると、仮想コントローラーが2P扱いになることがあります。
- **スト6を後から起動する**: `python lab.py ping` を実行してカウントダウン中にスト6を起動すると、仮想コントローラーが認識されやすくなります。
- **Steam入力**: Steam の「コントローラー設定」で Xbox コントローラーの Steam 入力を OFF にすると、改善することがあります。

## 5. 注意

- **オフライン専用**: 仮想コントローラーは、トレーニングモード（オフライン）だけで使ってください。
- **前面に置いたまま**: 実験中は、マウスやキーボードを触らず、スト6を前面に置いたままにしてください。
- **CPU負荷**: 正確な待ち時間のために、実験中は CPU を1コア分使います。

## 仕組み（開発者向け）

| ファイル | 役割 |
| --- | --- |
| `sf6lab/inject.py` | 仮想パッドと時間管理（`perf_counter` で目標時刻の約2ms前まで sleep し、残りは待ち続ける） |
| `sf6lab/history.py` | 入力履歴の読み取り（アイコンの見本を自動で覚え、正規化相関で照合） |
| `sf6lab/outcome.py` | 技の判別（ボタン後1秒間の画面変化を3×3マス×30区間の特徴にして、最も近い技を選ぶ） |
| `sf6lab/models.py` | 読み取りモデル3種と、スト6式のコマンド判定（ボタンから逆向きに探す方式） |
| `sf6lab/experiments.py` | 実験A・B・C。開始時刻を毎回ランダムにずらし、条件をシャッフル |
| `sf6lab/report.py` | 集計とモデル判定（対数尤度） |
| `lab.py selftest` | スト6なしで、シミュレーション上の既知の正解を実験と集計で当てられるか確認 |
